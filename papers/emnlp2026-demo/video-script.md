# Demo Video Script

Target length: 2.5 minutes maximum.

## Storyboard

1. Title card: FsVoice, a platform for voice-first conversational applications.
2. Show the platform diagram: host shell, realtime voice, orchestration, tools, context, optional retrieval.
3. Introduce Speak2Docs as one application built from the platform.
4. Show selected source list with built-in or imported source ready.
5. Start realtime voice session.
6. Ask: "What is the main claim of this paper?"
7. Show transcript finalization and activity/log evidence if visible.
8. Let the spoken answer play.
9. Ask a retrieval-specific follow-up: "Which section supports that answer?"
10. Briefly show architecture diagram: Voice agent, Oracle agent, Host agent, retrieval tools.
11. End with repo link and install/demo link.
