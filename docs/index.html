Speak2Docs Support

Speak2Docs lets you ask questions about selected PDFs, Markdown files, JSON files, and bundled document indexes using realtime voice.

Getting Started

  1. Open Settings and enter your OpenAI API key.
  2. Use the compact Sources area on the main screen to see which ready sources will be used for answers.
  3. Tap Sources to open Library when you need to search, preview, select, clear selections, delete, or retry sources.
  4. Tap + to add a PDF, Markdown, JSON, or Speak2Docs index bundle. Newly added ready sources stay selected alongside your existing selections.
  5. Tap Connect, review the OpenAI Data Processing screen, and allow OpenAI processing.
  6. Ask a question about the selected sources.

Troubleshooting

  • If Connect is unavailable, confirm that an OpenAI API key is saved and at least one ready source is selected.
  • If voice input does not start, confirm that microphone permission is enabled for Speak2Docs in device settings.
  • If a long source list is hard to scan, tap Sources to open Library and use search, preview, and Clear all selections.
  • If answers miss relevant context, try selecting fewer sources, enabling lexical filtering, or rebuilding the source index. The Describe Visuals setting affects future PDF processing; existing selected-source indexes should remain searchable when the setting changes.
  • If the app crashes after an update, reinstall the app and send the device crash report through the App Store support contact.

Notes

Speak2Docs does not create an app account. Realtime voice question answering requires your OpenAI API key, microphone permission, and in-app permission to send selected audio, prompts, document context, and optional PDF visual crops to OpenAI for processing.
