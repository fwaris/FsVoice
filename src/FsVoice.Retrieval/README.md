# FsVoice.Retrieval

Source loading, indexing, ranking, keyword enrichment, and document-structure PDF parsing for FsVoice.

This package embeds `PP-DocLayout-M` ONNX for offline document layout detection. FsVoice code is MIT licensed; the embedded model is Apache-2.0. See `PP-DocLayout-M-NOTICE.md` in the package for model attribution and checksum details.
